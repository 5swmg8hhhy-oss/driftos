# DriftOS TV
Экспериментальный лаунчер для Android TV / Xiaomi. Не прошивка и не замена Android.
## Сборка без Android Studio
1. Загрузите **содержимое** этой папки в корень репозитория GitHub (включая скрытую `.github`).
2. Вкладка Actions → Build DriftOS TV APK → Run workflow.
3. После успешной сборки скачайте artifact `DriftOS-TV-APK`, распакуйте и установите `app-debug.apk` на телевизор.
4. Сборка использует Gradle 8.9 через GitHub Actions. 
## Возможности
Карточки с фокусом для пульта, список Android TV приложений, переход к настройкам, VPN-кнопка.
VPN-кнопка пытается открыть несколько известных клиентов; если клиент не найден, откройте его из списка приложений.
## Ограничения
Не протестировано на физическом Xiaomi. Приложение не заменяет системный HOME автоматически. Приложения без LEANBACK могут не отображаться.
